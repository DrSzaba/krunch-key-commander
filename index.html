What it does

🔐

One password to remember

Make one master password and EZ Password Manager remembers the rest. Every login gets a name, username, password, website, category and notes. Star your favorites so they sit at the top.

📋

Copy & paste, done

Click an item, then just click the username or password to copy it (or press the big Copy buttons). Want only part of it? Highlight it and press Ctrl+C. The clipboard wipes itself after 30 seconds. Open website takes you straight to the login page.

🎲

Strong passwords made for you

The built-in password maker gives you random ones, or easy-to-type ones like Maple-River-Comet-42. A strength meter shows weak ones, and the vault counts reused passwords for you.

New in 3.1

🔄

All your computers, one vault

Click Vault → Sync with Dropbox on each computer. Add or change a password on one, and it shows up on the others within seconds. Passwords that were already on each computer get combined, and duplicates are skipped.

🛡

Still locked tight

The file in Dropbox is the same AES-256 encrypted vault. Dropbox, or anyone who gets into your Dropbox, only sees noise without your master password.

🤝

Nothing gets lost

If two computers save at the same moment, Dropbox makes a "conflicted copy". EZ Password Manager spots it and combines it for you. Sync is optional: skip it and everything stays on this PC only.

Simple on purpose

Categories on the left  →  your list in the middle  →  big Copy buttons on the right

Safe by design

Your vault is one file, encrypted with AES-256 (the same encryption banks and Windows itself use). The key is made from your master password with 600,000 rounds of PBKDF2, so guessing is painfully slow. Without the master password the file is just noise.

It never connects to the internet by itself — only if you turn on Dropbox sync, and then Dropbox only carries the encrypted file. There is no account to hack, no company that can be breached, and no monthly fee. Locks itself after 5 minutes. Import your passwords from Chrome, Edge, Firefox or another password app (CSV), and save encrypted backups any time.

One honest warning: if you forget your master password, nobody can recover it — not even the person who made this program. That is exactly what keeps your passwords safe. Write it down and keep it somewhere secure.

How to install

  1. Click Download for Windows above and save the zip file.
  2. Right-click the zip → Extract All, then double-click EZ-Password-Manager-Setup.exe.
  3. Next, Install, Finish. Open it from the Desktop shortcut and create your master password.
Seeing a blue "Windows protected your PC" box? That's Windows being careful with any new program from a small maker. Click More info, then Run anyway. Everything is inside the setup — nothing else to download.

Questions

I used Krunch Key Commander. Do I lose my passwords?

No. Krunch Key Commander is now called EZ Password Manager. Install it on the same computer and open it: your passwords come over by themselves and you unlock with the same master password. Once you see them, you can uninstall Krunch Key Commander from Settings → Apps.

How do I keep the same passwords on all my computers?

Install Dropbox and EZ Password Manager on each computer. On each one, unlock it and click Vault → Sync with Dropbox (all my computers) → Use my Dropbox folder. The first computer puts its vault in Dropbox; the others add their passwords into it. If a computer used a different master password, it asks for the Dropbox vault's master password once.

How do I move my passwords to another computer?

Easiest: use Dropbox sync (above). Or, without Dropbox: On the old computer: Vault → Save an encrypted backup, and copy that file to a USB stick. On the new computer, install EZ Password Manager and click I already have a backup file (or Vault → Bring in passwords from a backup file).

Does it work on a phone or Mac?

Not yet — it's for Windows 10 and 11 (64-bit).

Where are my passwords stored?

In one encrypted file on your PC. The Vault menu has "Where is my vault file?" and "Save an encrypted backup" so you can copy it to another computer or a USB stick.

Can I bring in passwords from my browser?

Yes. Export them from Chrome, Edge or Firefox as a CSV file, then use Vault → Import. Delete the CSV afterwards (it's plain text).

Habla español?

Sí. Un botón cambia todo el programa entre inglés y español.

Something went wrong.

The program keeps a note of any problem in %LOCALAPPDATA%\EZPasswordManager\crash.log. Send that text and describe what you were doing.
